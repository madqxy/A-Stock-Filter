# GUI 使用指南

## 启动

```bash
python main.py
```

或双击 `启动工具.bat`。

## 操作步骤

### 1. 数据收集

1. 点击 **开始收集** 按钮
2. 等待 5 个阶段完成：
   - 阶段1：获取股票清单（~5500只）
   - 阶段2：拉取实时行情
   - 阶段2.5：过滤 ST/退市/市值<80亿
   - 阶段3：拉取历史K线（首次较慢，后续增量更新）
   - 阶段4：计算技术指标（MA/KDJ/MACD等）
3. 完成后数据自动显示在表格中

### 2. 数据筛选

1. 在 **筛选器** 下拉框选择策略（如"放量双金叉盈利"）
2. 点击 **参数设置** 调整参数（可选）
3. 点击 **筛选** 按钮
4. 表格显示符合条件的股票

### 3. 数据导出

- **全量导出**：导出所有股票数据到 Excel
- **导出筛选**：仅导出筛选结果到 Excel

### 4. 查看股票详情

双击表格中的某一行，自动在浏览器打开同花顺个股页面。

> 注：指数行（上证/深证/沪深300/中证1000）不在表格中显示，但保留用于筛选基准比对。

## 参数设置

点击 **参数设置** 按钮打开对话框，可调整：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 放量倍数 | 成交量 / N日平均成交量 | 1.5 |
| 市盈率上限 | PE > 0 且 < 此值 | 200 |
| 时间窗口 | 换手率极值计算窗口 | 20日 |
| 均线周期 | MA 计算周期 | 20日 |
| 对比基准 | 跑赢大盘的基准指数 | 沪深300 |

## 分页浏览

- 每页显示 200 行
- 使用 **上一页 / 下一页** 按钮翻页
- 底部显示当前行号和总行数

## 日志区域

底部日志区域显示：
- 各阶段进度信息
- 警告和错误信息
- 数据质量诊断信息（如 `[DIAG]` 开头的输出）

## 快捷键

- `Ctrl+C`：复制选中行
- 双击行：打开同花顺个股页面
