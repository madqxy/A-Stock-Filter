# 数据源说明

## 概述

系统使用多个数据源获取 A 股行情数据，优先使用腾讯 HTTP 直连接口以获得最佳性能。

## 数据源列表

### 1. akshare

**用途**：获取 A 股股票清单、指数行情

**接口**：
- `ak.stock_info_a_code_name()` - 获取全部A股代码和名称
- `ak.stock_zh_index_spot_em()` - 获取指数实时行情
- `ak.stock_zh_index_daily_em()` - 获取指数历史K线

**特点**：
- 底层封装了东方财富、新浪等数据源
- 适合获取股票清单和指数数据
- 不适合高频调用（有频率限制）

**使用场景**：
- Stage 1：获取~5500只A股代码
- 指数块：获取4个主要指数的行情和K线

---

### 2. 腾讯实时行情 API

**URL**：`http://qt.gtimg.cn/q=`

**用途**：批量获取实时行情数据

**请求格式**：
```
http://qt.gtimg.cn/q=sh600000,sz000001,sh600036,...
```

每次最多100只股票，用逗号分隔。

**响应格式**：
```
v_sh600000="1~浦发银行~600000~10.24~10.20~...~906890~...~1.09~...~0.47~4.58~1971.61~...";
```

字段用 `~` 分隔，关键字段：
- [1] 名称
- [2] 代码
- [3] 最新价
- [6] 成交量（手）
- [32] 涨跌幅（%）
- [38] 换手率（%）
- [39] 市盈率（动态）
- [44] 总市值（亿元）

**特点**：
- 批量请求，100只/次
- 响应速度快（~0.1s/批）
- 盘中实时更新，盘后返回收盘数据

**使用场景**：
- Stage 2：获取全部股票的实时行情

---

### 3. 腾讯K线 API

**URL**：`http://web.ifzq.gtimg.cn/appstock/app/fqkline/get`

**用途**：获取历史日K线数据

**请求格式**：
```
http://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600000,day,2026-01-01,2026-07-01,300,qfq
```

参数说明：
- `param={市场}{代码}` - 股票标识（sh/sz/bj前缀）
- `day` - 日K线
- `start_date` - 起始日期（YYYY-MM-DD）
- `end_date` - 结束日期（YYYY-MM-DD）
- `300` - 最多返回300根K线
- `qfq` - 前复权

**响应格式**：
```json
{
  "data": {
    "sh600000": {
      "qfqday": [
        ["2026-01-02", "10.00", "10.24", "10.30", "9.95", "906890"],
        ...
      ]
    }
  }
}
```

每根K线字段：`[日期, 开盘, 收盘, 最高, 最低, 成交量(手)]`

**特点**：
- 单只股票请求
- 返回指定日期范围内的K线（最多300根）
- 只返回 start_date 之后的数据
- 前复权价格

**重要**：
- API 只返回 start_date 之后的K线
- 如果 start_date = 今天，只返回今天1根K线
- 计算 MA120 需要至少120根K线

**使用场景**：
- Stage 3：批量获取历史日K线

## 数据源对比

| 数据源 | 速度 | 批量 | 适用场景 |
|-------|------|------|---------|
| akshare | 慢（2s/stock） | 否 | 股票清单、指数数据 |
| 腾讯实时 | 快（0.1s/100stocks） | 是（100/批） | 实时行情 |
| 腾讯K线 | 中（0.1s/stock） | 否 | 历史K线 |

## 市场代码前缀

A股代码需要添加市场前缀：

| 前缀 | 市场 | 代码规则 |
|------|------|---------|
| `sh` | 上海 | 6开头 |
| `sz` | 深圳 | 0、3开头 |
| `bj` | 北京 | 83、87、43、920开头 |

示例：
- `600000` → `sh600000`（浦发银行）
- `000001` → `sz000001`（平安银行）
- `836149` → `bj836149`（吉林碳谷）

## 成交量单位

**重要**：系统中成交量统一使用 **万手** 单位。

- 1手 = 100股
- 1万手 = 10,000手 = 1,000,000股

腾讯API返回的成交量单位是 **手**，系统自动转换为万手：
- K线成交量：`volume / 10000`（手 → 万手）
- 实时成交量：`volume / 1000000`（股 → 万手）

## 数据更新频率

| 数据类型 | 更新频率 | 说明 |
|---------|---------|------|
| 股票清单 | 7天 | JSON缓存TTL |
| 实时行情 | 每日 | 按日期存储Parquet |
| 历史K线 | 增量 | 只拉取新增日期 |
| 指数行情 | 每日 | 随主流程拉取 |

## 故障处理

### 腾讯API 501错误

**原因**：
- 请求的日期范围无数据（如非交易日）
- 频率限制

**处理**：
- 系统自动重试3次（tenacity）
- 批量请求间加0.1秒延迟
- 部分股票失败不影响整体

### 数据缺失

**原因**：
- 股票停牌
- 新上市股票历史数据不足

**处理**：
- 实时数据缺失时从K线补充
- 市值缺失时用总股本×价格计算
- MA计算需要至少120根K线
