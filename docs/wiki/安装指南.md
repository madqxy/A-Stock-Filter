# 安装指南

## 环境要求

- Python 3.10 或更高版本
- pip 包管理器
- 网络连接（用于拉取 A 股行情数据）

## 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/your-username/A股数据分析.git
cd A股数据分析
```

### 2. 创建虚拟环境（推荐）

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. 安装依赖

```bash
# 运行时依赖
pip install -r requirements.txt

# 开发依赖（包含 pytest）
pip install -r requirements-dev.txt
```

### 4. 验证安装

```bash
# 运行测试
pytest tests/

# 启动 GUI
python main.py
```

## 常见问题

### Q: pip install 失败怎么办？

尝试使用国内镜像源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q: 运行时报错 "ModuleNotFoundError"

确认已激活虚拟环境，并重新安装依赖：

```bash
pip install -r requirements.txt --force-reinstall
```

### Q: Windows 下启动 GUI 闪退

使用命令行启动查看错误信息：

```bash
python main.py
```

### Q: 数据拉取失败或超时

- 检查网络连接
- 腾讯 API 可能有频率限制，等待几分钟后重试
- 非交易时间（15:00 后）部分数据可能不完整

## Windows 快捷启动

项目包含 `启动工具.bat`，双击即可启动 GUI。

可创建桌面快捷方式：
1. 右键 `启动工具.bat` → 发送到 → 桌面快捷方式
2. 或复制已有的 `A股数据分析.lnk` 到桌面
