# 筛选策略

## 概述

系统提供 5 种筛选策略，所有策略都支持参数自定义。

## 策略详解

### 1. 右侧买入 (right_buy)

**默认策略**，趋势确立后的买入信号。整合了原"放量双金叉盈利"和"右侧拐点买入"。

**筛选条件**：
- 最新价 > 20日均线（站上均线）
- 5日均价 > 20日均价（短期趋势向上）
- 最新成交量 > 放量倍数 × 5日平均成交量
- KDJ/MACD金叉（根据金叉模式：双金叉=AND，单金叉=OR）
- 市盈率 > 0 且 < 上限
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找趋势确立、放量启动的买入时机。

**可调参数**：
- `--golden-mode`：金叉模式（both=双金叉，either=单金叉，默认both）
- `--volume-multiplier`：放量倍数（默认1.5）
- `--pe-max`：市盈率上限（默认9999=不限）
- `--vs-index`：对比基准（默认沪深300）

**示例**：
```bash
# 双金叉 + 放量1.5倍 + PE<30
python main.py --cli --filter 右侧买入 --golden-mode both --pe-max 30

# 单金叉 + 放量2倍
python main.py --cli --filter 右侧买入 --golden-mode either --volume-multiplier 2.0
```

---

### 2. 均线多头排列 (ma_bullish)

经典趋势跟踪策略。

**筛选条件**：
- 短期均线 > 中期均线 > 长期均线
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找多头排列、趋势明确的股票。

**可调参数**：
- `--ma-short`：短期均线天数（默认5日）
- `--ma-medium`：中期均线天数（默认20日）
- `--ma-long`：长期均线天数（默认60日）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter 均线多头排列 --ma-short 10 --ma-medium 30 --ma-long 60
```

---

### 3. 放量突破 (volume_breakout)

量价齐升突破信号。

**筛选条件**：
- 最新价 > N日均线
- 最新成交量 > 放量倍数 × 5日平均成交量
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找放量突破关键均线的股票。

**可调参数**：
- `--volume-multiplier`：放量倍数（默认1.5）
- `--ma-window`：均线周期（默认20日）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter 放量突破 --volume-multiplier 2.0 --ma-window 60
```

---

### 4. 止跌缩量 (stabilize_volume_shrink)

盈利 + 止跌 + 缩量，可选要求下跌趋势（左侧拐点）。整合了原"左侧拐点买入"和"盈利止跌缩量"。

**筛选条件**：
- 市盈率 > 0 且 < 上限（盈利低估）
- N日最大日波幅 < 阈值（止跌）
- 最新成交量 < 缩量倍数 × 5日平均成交量（缩量）
- 可选：最新价 < MA（下跌趋势，左侧拐点）

**适用场景**：
- `require_downtrend=false`（默认）：寻找盈利稳定、交投清淡的股票，可能即将变盘
- `require_downtrend=true`：寻找下跌末期、卖盘枯竭的股票（左侧抄底）

**可调参数**：
- `--pe-max`：市盈率上限（默认30）
- `--ma-window`：均线周期（用于下跌趋势判断，默认20日）
- `--window`：波幅观察天数（默认10日）
- `--fluctuation-pct`：波幅上限%（默认3.0）
- `--volume-ratio`：缩量倍数（默认0.8）
- `--require-downtrend`：要求下跌趋势（true/false，默认false）

**示例**：
```bash
# 止跌缩量（不限趋势）
python main.py --cli --filter 止跌缩量 --pe-max 20 --fluctuation-pct 2.0

# 左侧拐点（要求下跌趋势）
python main.py --cli --filter 止跌缩量 --require-downtrend true --pe-max 15
```

---

### 5. 止涨放量下跌 (stall_volume_drop)

看跌反转信号：股票出现死叉（KDJ或MACD），价格跌破均线，伴随放量下跌，可能是主力出货。

**筛选条件**：
- 死叉信号（根据配置模式）
- 最新价 < N日均线（跌破均线）
- 涨跌幅 < 0（当日下跌）
- 最新成交量 > 放量倍数 × 5日平均成交量（放量）

**适用场景**：识别看跌反转信号，规避风险。结合死叉指标比单纯均线判断更可靠。

**可调参数**：
- `--volume-multiplier`：放量倍数（默认1.5）
- `--ma-window`：均线周期（默认20日）
- `--death-cross-mode`：死叉模式（默认either）
  - `both`：双死叉（KDJ AND MACD）- 最严格
  - `either`：单死叉（KDJ OR MACD）- 默认
  - `kdj`：仅KDJ死叉
  - `macd`：仅MACD死叉

**示例**：
```bash
# 默认模式（单死叉）
python main.py --cli --filter 止涨放量下跌 --volume-multiplier 2.0

# 双死叉模式（更严格）
python main.py --cli --filter 止涨放量下跌 --death-cross-mode both

# 仅KDJ死叉
python main.py --cli --filter 止涨放量下跌 --death-cross-mode kdj
```

## 对比基准说明

所有策略都支持选择对比基准，筛选跑赢大盘的股票。

| 基准代码 | 指数名称 | 特点 |
|---------|---------|------|
| `csi300` | 沪深300 | 大盘蓝筹代表（默认） |
| `csi500` | 中证500 | 中盘股代表 |
| `csi1000` | 中证1000 | 小盘股代表 |
| `sh000001` | 上证指数 | 上海市场整体 |
| `sz399001` | 深证成指 | 深圳市场整体 |
| `star50` | 科创50 | 科创板代表 |
| `chinext` | 创业板指数 | 创业板代表 |

**选择建议**：
- 投资大盘股：选择沪深300
- 投资中小盘：选择中证500或中证1000
- 投资科技股：选择科创50或创业板指数

## 组合使用

多个参数可以组合使用：

```bash
# 右侧买入 + 双金叉 + PE<30 + 跑赢中证1000
python main.py --cli --filter 右侧买入 --golden-mode both --pe-max 30 --vs-index csi1000

# 止跌缩量 + 左侧拐点 + 严格条件
python main.py --cli --filter 止跌缩量 --require-downtrend true --pe-max 15 --fluctuation-pct 2.0 --volume-ratio 0.5
```

## 筛选结果解读

筛选结果包含以下关键信息：

| 字段 | 说明 |
|------|------|
| 代码、名称 | 股票基本信息 |
| 最新价、涨跌幅 | 当日行情 |
| 5/10/20/60/120日均价 | 技术指标 |
| 市盈率、市值 | 基本面指标 |
| 最新成交量、5日平均成交量 | 量能指标 |
| 换手率极值 | 活跃度指标 |
| KDJ/MACD金叉、KDJ/MACD死叉 | 技术信号 |
