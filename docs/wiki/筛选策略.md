# 筛选策略

## 概述

系统提供 8 种筛选策略，所有策略都支持参数自定义。

## 策略详解

### 1. 放量双金叉盈利 (volume_breakout_golden_profit)

**默认策略**，综合量价、技术指标和基本面。

**筛选条件**：
- 最新价 > N日均线（默认20日）
- 最新成交量 > 放量倍数 × 5日平均成交量
- KDJ金叉 = 是
- MACD金叉 = 是
- 市盈率 > 0 且 < 上限（默认200）
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找放量突破、技术面看涨、估值合理的股票。

**可调参数**：
- `--volume-multiplier`：放量倍数（默认1.5）
- `--pe-max`：市盈率上限（默认200）
- `--ma-window`：均线周期（默认20日）
- `--vs-index`：对比基准（默认沪深300）

**示例**：
```bash
python main.py --cli --volume-multiplier 2.0 --pe-max 150
```

---

### 2. 当前换手率N日最高 (turnover_above_max)

筛选换手率达到近期高位的股票。

**筛选条件**：
- 最新换手率 >= N日最高换手率
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找交投活跃、资金关注度高的股票。

**可调参数**：
- `--window`：时间窗口（默认20日，可选5/10/20/30/60日）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter turnover_above_max --window 30
```

---

### 3. 当前换手率N日最低 (turnover_below_min)

筛选换手率降至近期低位的股票。

**筛选条件**：
- 最新换手率 <= N日最低换手率
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找缩量调整、可能即将启动的股票。

**可调参数**：
- `--window`：时间窗口（默认20日）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter turnover_below_min --window 10
```

---

### 4. 右侧拐点买入 (right_corner_buy)

技术面右侧交易信号。

**筛选条件**：
- 最新价 > 20日均线
- 5日均线 > 20日均线（短期趋势向上）
- 最新成交量 > 放量倍数 × 5日平均成交量
- KDJ金叉 = 是 或 MACD金叉 = 是
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找趋势确立、放量启动的买入时机。

**可调参数**：
- `--volume-multiplier`：放量倍数（默认1.5）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter right_corner_buy --volume-multiplier 1.8
```

---

### 5. 均线多头排列 (ma_bullish)

经典趋势跟踪策略。

**筛选条件**：
- 短期均线 > 中期均线 > 长期均线
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找多头排列、趋势明确的股票。

**可调参数**：
- `--ma-short`：短期均线天数（默认5日）
- `--ma-medium`：中期均线天数（默认20日）
- `--ma-long`：长期均线天数（默认60日）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter ma_bullish --ma-short 10 --ma-medium 30 --ma-long 60
```

---

### 6. 放量突破 (volume_breakout)

量价齐升突破信号。

**筛选条件**：
- 最新价 > N日均线
- 最新成交量 > 放量倍数 × 5日平均成交量
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找放量突破关键均线的股票。

**可调参数**：
- `--volume-multiplier`：放量倍数（默认1.5）
- `--ma-window`：均线周期（默认20日）
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter volume_breakout --volume-multiplier 2.0 --ma-window 60
```

---

### 7. KDJ金叉 (kdj_golden)

纯技术指标筛选。

**筛选条件**：
- KDJ金叉 = 是
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找KDJ指标看涨信号。

**可调参数**：
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter kdj_golden --vs-index csi500
```

---

### 8. MACD金叉 (macd_golden)

纯技术指标筛选。

**筛选条件**：
- MACD金叉 = 是
- 涨跌幅 > 对比基准涨跌幅

**适用场景**：寻找MACD指标看涨信号。

**可调参数**：
- `--vs-index`：对比基准

**示例**：
```bash
python main.py --cli --filter macd_golden
```

---

## 对比基准说明

所有策略都支持选择对比基准，筛选跑赢大盘的股票。

| 基准代码 | 指数名称 | 特点 |
|---------|---------|------|
| `csi300` | 沪深300 | 大盘蓝筹代表（默认） |
| `csi500` | 中证500 | 中盘股代表 |
| `csi1000` | 中证1000 | 小盘股代表 |
| `sh000001` | 上证指数 | 上海市场整体 |
| `sz399001` | 深证成指 | 深圳市场整体 |
| `star50` | 科创50 | 科创板代表 |
| `chinext` | 创业板指数 | 创业板代表 |

**选择建议**：
- 投资大盘股：选择沪深300
- 投资中小盘：选择中证500或中证1000
- 投资科技股：选择科创50或创业板指数

## 组合使用

多个参数可以组合使用：

```bash
# 放量2倍 + PE<150 + 跑赢中证1000
python main.py --cli --volume-multiplier 2.0 --pe-max 150 --vs-index csi1000

# 均线多头 + 自定义周期
python main.py --cli --filter ma_bullish --ma-short 10 --ma-medium 30 --ma-long 60
```

## 筛选结果解读

筛选结果包含以下关键信息：

| 字段 | 说明 |
|------|------|
| 代码、名称 | 股票基本信息 |
| 最新价、涨跌幅 | 当日行情 |
| 5/20/60/120日均价 | 技术指标 |
| 市盈率、市值 | 基本面指标 |
| 最新成交量、5日平均成交量 | 量能指标 |
| 换手率极值 | 活跃度指标 |
| KDJ/MACD金叉 | 技术信号 |
